# 接入 QQ 机器人

插件很适合接给 QQ 机器人这类「群友会分享视频」的场景。用 [dsh-qq](https://github.com/h-D-ACE/dsh-qq) 的可以一键适配；用别的桥接的，按工具清单和门卫协议接。

## dsh-qq

dsh-qq 是独立进程的 QQ 桥接（NapCat / SnowLuma 之类的 OneBot + 控制台）。接上它要两步，都在「收件箱 → 设置 → 门卫」里。

### 1. 选门卫来源

门卫来源选「dsh-qq」，填桥接目录（有 `config.json` 和 `src/bridge.js` 的那个），保存。下面会显示连不连得上：主人 QQ、OneBot、桥接控制台、会话数。

插件从桥接目录读这些：`config.json` 里的 `ownerQQ`、`snowluma.httpUrl` / `accessToken`、`consolePort`，以及 `state/console-token`、`state/sessions.json`。

### 2. 一键适配

点「一键适配」，给桥接打三个补丁：

| 补丁 | 作用 |
| --- | --- |
| 工具白名单 | 把本插件的工具按全名加进 `qq-tool-restrict.mjs` 的 `SAFE_EXACT`，不按前缀放行 |
| 分享卡片 | 桥接默认把 QQ 卡片显示成「[卡片消息]」，改成「[卡片·哔哩哔哩] 标题 链接」，她才看得到链接 |
| 偶发报错 | 模型偶尔把工具参数写成坏 JSON（`MALFORMED_RESPONSE`）时只记日志，不往群里发「AI 处理出错」 |

改的是桥接的源码，所以有几条保护：

- 第一次改之前备份成 `.bak-bili-eyes`；
- 已经打过的跳过；
- 桥接升级后找不到要改的那一行时只报出来，不硬改；
- 「还原补丁」能一字不差地改回去。

改完在桥接的控制中心重启桥接。插件升级后如果加了新工具，这里会显示「工具白名单缺 N 个」，再点一次「一键适配」、重启桥接就补上了。

### 接好之后

- 主人私聊里「直接做」的直接发，群里只起草；主人用自己的话同意就算。
- 需要告诉主人时，插件改写桥接里一个停用的定时任务再运行一次，她在主人私聊里醒来说；任务没有就自动建：
  - 「B站收件箱」：收件箱有新消息；
  - 「B站推荐」：自己逛想推荐给主人；
  - 「B站待同意」：自己逛起了要主人点头的草稿。
- 桥接不通时，用 OneBot 直接私聊主人一句。
- 群里的视频能认出是谁发的、谁叫她看的，「谁叫的」靠的就是这个。

## 群里省着用：谁叫她看视频

看视频、逛一圈很费 token。拉进人多的群以后，群友发的视频她都可能去看。「看视频 → 谁叫的」里有一张表：行是看视频（含放大看）和逛，列是谁叫的。每格三档：

| 档位 | 说明 |
| --- | --- |
| 看 | 照常看 |
| 只看简介 | 标题、简介、B站 AI 总结、热评、弹幕热词。不下载、不出分镜，几百 token 就够；逛就改成快速逛一圈。她知道自己没看画面，不会装作看过 |
| 不看 | 不看，告诉她一句为什么，让她一句话带过、别再试 |

谁叫的分四类：**主人**、**熟人**（填 QQ 号）、**别人**、**说不清**。插件按 QQ 消息记录判断：

- 谁发了这个视频：链接、短链、BV 号、分享卡片都认；
- 谁引用回复了它并 @ 她；
- 几个人都沾边时按最宽的算，比如主人引用群友的链接说「看看」，就算主人叫的；
- 消息里没出现过的视频（她自己搜到的），看是谁 @ 她叫的；
- 主人私聊、DSH 本机窗口算主人。群友说「主人让你看的」不算数。

其他设置：

- **预设**：谁叫都看（默认）/ 群友只看简介 / 只看主人和熟人的 / 只看主人的。怕费 token 的选「群友只看简介」就行。
- **每人每天上限**：熟人、别人可以各设一个（默认不限），超了「看」降成「只看简介」。看过的视频再看不算。
- **个别群换预设**：比如自己的交流群放开，大群只看主人的。

限制：

- 认人要门卫给消息记录（门卫协议 v2 的 `recentMessages`）。dsh-qq 适配自带；内置门卫和不支持的门卫认不出群里是谁，群里一律算「说不清」。
- 只管她自己调用的工具。设置页试看、自己逛、守评论区、收件箱不受影响。
- 只省「看」的钱。她在群里被叫醒、聊天那一轮花的 token 归桥接管，插件管不到。

设计细节见 [群聊省额度-设计](../群聊省额度-设计.md)。

## 其他桥接

- **工具白名单**：从 `dsh-bili-eyes/tool-list` 导入 `READ_TOOLS`、`WRITE_TOOLS`，按全名加进桥接的白名单。见 [工具](工具.md#给其他插件和桥接用)。
- **门卫**：在桥接自己的 `apply` 里 `ctx.set('biliEyesGate', {...})` 提供门卫服务，插件就知道哪个会话是主人、主人说过什么，也能把收件箱、推荐、待同意的草稿转达出去。实现了 `recentMessages` 的门卫，「谁叫的」就能在群里分人。完整协议见 [门卫协议](../门卫协议.md)。
- 不提供门卫也能用：插件退回内置门卫，桥接会话只能起草，在设置页同意。
