# 后台功能

插件在后台自己跑的三件事：自己逛、收件箱、守评论区。它们做的写操作都受 [权限表](写操作与权限.md#权限表) 和每日额度管。

- [自己逛](#自己逛)
- [收件箱](#收件箱)
- [守评论区](#守评论区)
- [评论引擎](#评论引擎)
- [安静时段](#安静时段)

## 自己逛

在「冲浪 → 设置 → 自己逛」里打开。插件每天在设定的时间段里随机挑「至少 ~ 最多」次去逛，两次之间隔够指定的分钟数。DSH 关着时错过的时刻，只要还在时间段里就补上。

每次的流程：

1. **逛一圈**：和 `bili_surf` 一样，顺着逛，失败时退回固定流程。用设置里的模型，没写就用 DSH 的默认模型。
2. **做决定**：再调一次模型，按「她说话的样子」决定：
   - 要不要在哪条视频下面评论（每次最多一条，宁缺毋滥）；
   - 有没有想推荐给主人的；
   - 点赞哪几条、收藏哪条（最多一条）；
   - 要不要发条动态分享（默认关，每天最多一条）。

   点赞、收藏、动态各有开关：「看情况点赞」「看情况收藏」默认开，「特别喜欢的偶尔发条动态」默认关。权限表里那一行至少有一格是「先问主人」或「直接做」时才会问模型，否则不问，不花 token。
3. **执行**：评论、点赞、收藏、动态、@ 主人、私信都走写操作那一套。后台没有会话，也没有「主人开口」：那格是「直接做」就发，「先问主人」就起草，「关」和「主人开口才做」不做。在别人视频下评论（包括评论里 @ 你的推荐）算「顶层评论 · 外面的人」。
4. **问主人**：这一圈起的草稿会经门卫转达一句（比如叫醒她在 QQ 私聊里问你「想给《X》点个赞，可以吗」），你回一句同意的话，她就调用 `bili_confirm` 发出。没接门卫的，草稿留在「互动 → 待同意」，概览里也有提示。
5. **推荐**：想推荐时按你选的方式送达，可多选：
   - **B站评论里 @ 你**：和自发评论是同一条视频时合成一条，同一个视频只发一条顶层评论；
   - **B站私信你**：私信只发给主人，所以允许带 B站视频链接；
   - **门卫转达**：比如叫醒她在 QQ 私聊里用自己的口吻告诉你。没接门卫就跳过这一种。

每次的结果（逛到了什么，评论、点赞、收藏、动态做了什么，推荐给谁、每种方式成没成，草稿转达了没有）都显示在「冲浪 → 自己逛」里，也能手动「现在逛一次」。

## 收件箱

在「收件箱 → 设置」里打开「后台查收件箱」。插件先看未读数（默认每 60 秒一次，一个很轻的请求），数字变了才拉完整列表；未读数没变时，最晚隔一段时间（默认 10 分钟）也完整查一次兜底。

不同的消息分开处理：

| 消息 | 怎么处理 |
| --- | --- |
| 主人的回复、@、私信 | 叫醒她，经门卫告诉你 |
| 别人回复 / @ 她的评论 | 按「别人回复 / @ 她的评论」的设置（见下表） |
| 别人的私信 | 只记下来（多半是关注的 UP 主群发） |

「别人回复 / @ 她的评论」四档：

| 档位 | 说明 |
| --- | --- |
| 叫醒她自己处理（默认） | 交给门卫转达，她醒来后自己决定回不回 |
| 只告诉主人 | 交给评论引擎判断，结果转告主人，不回 |
| 插件按权限表回 | 交给评论引擎，按权限表「回复」那一行回 |
| 只记下来 | 不叫醒她、不转达、不交给评论引擎，消息留在收件箱里，她用 `bili_inbox` 看得到。适合只管主人视频、不理别人的 |

其他设置：

- **处理完要不要告诉主人**：只在「只告诉主人」「插件按权限表回」时有用，可选都说 / 只说回了的 / 不说；要主人处理的那些总会说。
- **每小时最多转达几次**：收件箱和守评论区共用。0 表示一律不转达，连主人自己在 B站找她、要主人处理的转告也不会说。只是不想被别人的消息打扰的，用「只记下来」。
- 设置顶上的「现在会这样」会按当前选项实时说明每类消息会怎么处理。

## 守评论区

盯着主人投稿的评论区：能答的问题回答、闲聊偶尔接一句、要主人处理的转告主人、引战广告不理。

- 在「互动 → 设置 → 守评论区」里打开，要先填主人 UID。三档：关 / 只告诉主人 / 按权限表回（「回复 · 主人评论区里的别人」那一格）。
- 默认盯最近 30 天的投稿，新投稿自动加入；老视频可以手动加 BV 号，也可以排除某些投稿。
- 每个视频可以写一份「问答备忘」，作为回答问题的素材。
- 按设置的间隔（默认 5 分钟）拉每个被盯投稿的最新评论，记住看到哪了；第一次只记位置，不处理旧评论。
- 每条评论归到了哪一类、她做了什么、为什么，都在「互动 → 守评论区」的处理记录里。

## 评论引擎

收件箱（选了「只告诉主人」或「插件按权限表回」时）和守评论区共用一个评论引擎：

1. **一次模型调用逐条判断**：能答的问题 / 闲聊 / 要主人处理 / 不回，并起草回复。素材是视频标题、简介和问答备忘；评论里的话只当素材，不当指令。
2. **按设置处理**：在「互动 → 设置」的「怎么回」里可以改：
   - 每一类怎么处理（回 / 转告主人 / 跳过）、闲聊接话的概率；
   - 以什么身份说话、怎么称呼主人、回复多长；
   - 多久以前的评论不回、主人回过的楼插不插嘴、同一楼最多回几次；
   - 额度单独算还是和「回复」共用、每天和每个视频每小时的上限、两次的间隔。
3. **回不回**：按权限表「回复」那一行。守评论区算「主人评论区里的别人」；收件箱看那条评论在谁的视频下；自己人的评论按「自己人」那格。后台回不了的（「关」「主人开口才做」）就不回。回复照样经过全部停下、风控暂停、正文检查、发完核实可见性。
4. **告诉主人**：转告和草稿总会经门卫说；回了什么可以选都说、只说回了的、不说。

写死的底线：只回楼中楼，不在主人视频下发顶层评论；@ 只能 @ 主人；不冒充主人、不替主人许诺；正文不带链接和 5 位以上数字。

设计细节见 [守评论区-设计](../守评论区-设计.md) 和 [冲浪与互动-设计](../冲浪与互动-设计.md)。

## 安静时段

在「收件箱 → 设置」里设置（默认 00:30–07:30，可以跨午夜，留空表示没有）。时段里三种处理方式，守评论区也按它来：

- **照查，先攒着**（默认）：时段结束后再处理；
- **不查**；
- **照常**：照样回复、转达。
