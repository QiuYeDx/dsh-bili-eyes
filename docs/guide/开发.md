# 开发

## 从源码安装

```bash
git clone https://github.com/QiuYeDx/dsh-bili-eyes.git
cd dsh-bili-eyes
npm ci
dsh plugin --profile desktop add link:<这个目录>
```

改完代码后重启 DSH 生效；设置页的改动刷新页面就能看到。

## 命令行

不经过 DSH 跑一次，方便调试：

```bash
node bin/cli.mjs look <链接> [--from 秒 --to 秒] [--out 目录]   # 分镜图存成 PNG
node bin/cli.mjs zoom <链接> --from 秒 --to 秒 [--cells 6]
node bin/cli.mjs find <关键词> [--order views] [--duration short] [--limit 6]
node bin/cli.mjs login                                          # 扫码登录 B站
node bin/cli.mjs status
```

## 本地预览设置页

```bash
npm run preview    # → http://127.0.0.1:3396
```

不用开 DSH。用的是同一套接口代码和**真实配置**（`~/.dsh/bili-eyes.json`），在预览里点「保存」会改到正在用的配置；「现在逛一次」「试看」也会真的去做。

## 测试

```bash
npm test
```

设置了 `DSH_TOOLS_PATH` 时，会用宿主的 `defineTool` 校验工具定义。

## 图标和横幅

- 插件图标：`assets/icon.svg`（DSH 插件列表里显示的就是它，`package.json` 的 `icon` 指向它）。
- README 顶部横幅：`assets/banner.webp`，源文件是 `assets/brand/banner.html`（图标从 `assets/icon.svg` 嵌进去）。改了图标或横幅文字后重新生成：

```bash
node assets/brand/render-banner.mjs    # 用无界面的 Chrome 渲染，2 倍图、圆角外透明
```

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/index.js` | 插件入口：注册工具、挂设置页、后台定时任务 |
| `src/look.js` | 看视频：下载、分镜、台词、B站上下文 |
| `src/surf.js` / `src/surf-agent.js` | 逛一圈：固定流程和顺着逛 |
| `src/auto-surf.js` | 自己逛 |
| `src/inbox.js` / `src/interact.js` | 收件箱和各个写操作工具 |
| `src/guard.js` / `src/engine.js` | 守评论区和评论引擎 |
| `src/act.js` | 写操作的统一把关：权限、额度、草稿、审计、风控 |
| `src/config.js` | 配置默认值、字段说明、校验、权限表 |
| `src/gate.js` / `src/adapters/` | 门卫和 dsh-qq 适配 |
| `src/client.js` / `src/api.js` | 设置页界面和它的接口 |
| `docs/` | 设计文档和使用文档，见 [文档目录](../README.md) |
