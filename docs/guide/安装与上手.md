## 安装

在 DSH「设置 → 插件」里添加插件，包名填 `dsh-bili-eyes`（npm 官方源和 npmmirror 都有），装完重启 DSH。也可以用命令行：

```bash
dsh plugin --profile desktop add dsh-bili-eyes
```

需要 DSH 0.2.1 前后的版本（在 0.2.1-rc.3 上验证过）。

## 安装检查

打开「设置 → B站伙伴 → 概览」，看「安装检查」：

| 项目 | 说明 |
| --- | --- |
| ffmpeg | 缺了就看不了画面，只有标题、简介、评论、字幕这些文字。点「下载 ffmpeg」，插件从 npm 镜像下载 `@ffmpeg-installer` / `@ffprobe-installer` 的现成包（约 50 MB，按 sha512 校验），放到 `~/.dsh/tools/ffmpeg/bin`。已经装了 ffmpeg 的不用管 |
| 视频下载 | 插件自己从 B站下载（DASH 画面 + 音轨，用 ffmpeg 合成），不需要 yt-dlp。装了 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 的可以在设置里把它设成首选或后备 |
| 其余各项 | B站登录、主人 UID、语音识别、门卫、收件箱都是可选的。每一项缺了会怎样、怎么补，检查里都写着 |

## 试一下

- **设置页**：「看视频 → 试看」里贴一个链接或关键词，跑一遍和工具调用相同的流程，看到的就是她拿到的分镜图和文字。
- **对话里**：直接说「帮我看看这个视频 `https://www.bilibili.com/video/BV…`」「B站上搜几个讲黑洞的科普」「这个视频的评论区在吵什么」，模型会自己调 `bili_look`、`bili_find`、`bili_comments`。

到这一步只用了只读能力，不会往 B站发任何东西。

## 按需打开更多

| 想要 | 在哪打开 | 详见 |
| --- | --- | --- |
| AI 字幕和总结、1080P 放大、按口味推荐、收件箱、写操作 | 「概览」扫码登录 B站（建议小号） | [登录 B站](#登录-b站) |
| 没字幕的视频也有台词 | 「设置 → 语音识别」 | [语音识别](#语音识别台词) |
| 让她点赞、收藏、评论、私信你、关注 | 「互动 → 设置」：先填你的 B站 UID，再在权限表里把要开的几格从「关」调上去，或点一个预设 | [写操作与权限](写操作与权限.md) |
| 每天自己逛几次，把好东西推荐给你 | 「冲浪 → 设置 → 自己逛」 | [后台功能](后台功能.md#自己逛) |
| 有人回复、@、私信她时告诉你，或让插件自己回 | 「收件箱 → 设置」 | [后台功能](后台功能.md#收件箱) |
| 替你守着投稿的评论区 | 「互动 → 设置 → 守评论区」（要先填主人 UID） | [后台功能](后台功能.md#守评论区) |
| 群里人多，看视频太费 token | 「看视频 → 谁叫的」，点个预设（比如「群友只看简介」） | [接入 QQ 机器人](接入QQ机器人.md#群里省着用谁叫她看视频) |
| 评论时用 B站表情、带表情包 | 「互动 → 表情」 | [写操作与权限](写操作与权限.md#表情和表情包) |
| 接 QQ 机器人 | 「收件箱 → 设置 → 门卫」 | [接入 QQ 机器人](接入QQ机器人.md) |

用顺了之前，写操作建议先用「先问主人」，熟了再考虑「直接做」。

## 登录 B站

建议用小号。最简单的是在「B站伙伴 → 概览」里点「扫码登录」，也可以在插件目录里用命令行：

```bash
node bin/cli.mjs login     # 弹出二维码，用 B站 App 扫码确认
node bin/cli.mjs status
```

登录后多出 AI 字幕、AI 总结和 1080P 放大，也才能用收件箱和写操作。

- 登录信息存在 `~/.dsh/bili-eyes/credential.json`（另导出一份 `cookies.txt` 给 yt-dlp），相当于账号密码，不要外传。
- 登录过期后自动退回不登录模式。

## 语音识别（台词）

视频没有字幕时，分镜会调用 `~/.dsh/asr.json` 里配置的 OpenAI 兼容 `/audio/transcriptions` 接口（沿用 dsh-video-storyboard 的约定）。在「设置 → 语音识别」里配置，二选一：

- **硅基流动**：填 API Key 即可，模型是 `FunAudioLLM/SenseVoiceSmall`。
- **本机或自建服务**：SenseVoice、FunASR、whisper 都行，填地址和模型名。可以再填一条启动命令，用到时才拉起服务，闲置 10 分钟后关掉。

补充说明：

- 保存时会保留文件里这个页面不管的字段（热词、术语表等）。
- API Key 只写不读，页面上看不到。
- 「测试」会发 1 秒静音过去，检查连不连得上、Key 对不对。
- 不配置也能用，只是没有台词。

## 使用条件

装上就能看视频、搜视频、逛 B站。下表说明每样东西缺了会怎样：

| 需要什么 | 必需吗 | 没有会怎样 |
| --- | --- | --- |
| DSH 0.2.1 前后 | 必需 | 太老的版本可能缺审批卡片、模型工具调用等接口 |
| ffmpeg / ffprobe | 看画面才需要 | 只返回标题、简介、热评、弹幕、字幕这些文字；设置页能一键下载 |
| B站登录（建议小号） | 可选 | 看视频照常（最高 480P）；没有 AI 字幕和总结、个性化推荐、关注动态、收件箱，也不能做任何写操作 |
| 账号等级 ≥ LV1 | 发评论才需要 | LV0（未转正）的账号 B站不让发评论和弹幕 |
| 支持工具调用的模型 | 「顺着逛」才需要 | 自动退回固定流程。在 DeepSeek 上验证过，其他服务商没测 |
| 语音识别 | 可选 | 没字幕的视频没有台词 |
| 主人的 B站 UID | 可选 | 不能 @ 主人、不能私信主人 |
| 门卫 | 可选 | 用内置门卫：本机窗口里「先问主人」时弹 DSH 审批卡片；QQ 这类桥接会话只能起草，在设置页同意；收件箱和推荐转达不到 QQ。见 [写操作与权限](写操作与权限.md#门卫) |

系统：只在 Windows 上完整验证过。macOS / Linux 的路径和 ffmpeg 下载已经处理，但没有实测，遇到问题欢迎提 issue。

## 升级

在「设置 → 插件」里有新版本时会提示可更新（「设置 → 关于」里也能检查更新），或者用命令行：

```bash
dsh plugin --profile desktop add dsh-bili-eyes@latest
```

升级后重启 DSH。接了 dsh-qq 的，新版本加了工具时，「收件箱 → 设置 → 门卫」会提示白名单缺几个，再点一次「一键适配」。

各版本的注意事项（完整变化见 [CHANGELOG](../../CHANGELOG.md)）：

| 升级 | 注意 |
| --- | --- |
| 0.8.0 → 0.8.1 | 没有新工具，dsh-qq 不用重新适配。开着「自己逛」、而且权限表「点赞、收藏」那一行有「先问主人」或「直接做」的，升级后她逛的时候会看情况点赞、收藏，不想要就在「冲浪 → 设置 → 自己逛」关掉。收件箱想安静：「别人回复 / @ 她的评论」选「只记下来」 |
| 0.7.0 → 0.8.0 | 没有新工具（`bili_comment` 只在开了表情包时多一个 `sticker` 参数），dsh-qq 不用重新适配。「谁叫的」默认谁叫都看。表情默认「少用」，不想要的在「互动 → 表情」选「不用」；表情包默认关。接的不是 dsh-qq 的，门卫协议多了可选动作 `recentMessages`（v2），不实现也能用，只是群里认不出是谁叫的 |
| 0.6.0 → 0.7.0 | 写操作的档位换成了权限表，守评论区、收件箱也改成按权限表回。老配置在读取时自动换算，行为不变；第一次在设置页保存后，配置文件里的旧键会被清掉。没有新工具 |

## 卸载

在「设置 → 插件」里卸载。

- 登录信息、记录、草稿在 `~/.dsh/bili-eyes/`，配置在 `~/.dsh/bili-eyes.json`，卸载不会删除，不要了自己删。
- 缓存目录在「设置 → 存储」里能看到。
- 用 dsh-qq「一键适配」打过补丁、想把桥接改回原样的，卸载前在「收件箱 → 设置 → 门卫」点「还原补丁」。
