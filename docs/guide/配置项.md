## 看视频

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `maxPerHour` | 30 | 每小时最多新看几个视频（缓存命中不算；放大看的上限是它的 2 倍） |
| `maxFindPerHour` | 60 | 每小时最多搜几次 |
| `maxFullSeconds` / `longWindowSeconds` | 7200 / 7200 | 这个时长以内看完整；更长的只看开头 `longWindowSeconds` |
| `secondsPerCell` / `maxSheets` | 60 / 4 | 每格大约覆盖多久；视频越长分镜图越多（每张 16 格），最多几张。30 分钟 = 2 张，1 小时 = 4 张 |
| `timeoutSeconds` | 150 | 分镜的最短超时；长视频按时长自动放宽（最多 10 分钟）。超时只返回文字 |
| `cacheHours` | 24 | 同一视频同一段的结果缓存多久 |
| `comments` / `danmaku` | 5 / true | 带几条热评、要不要弹幕统计 |
| `textBudget` | 2600 | 返回文字的大致字数上限，每多一张图再加 1000（超了先缩每格台词，每一格都保留） |
| `useLogin` | true | 有登录信息时使用 |
| `videoSource` | `auto` | 视频从哪下：`auto` 插件自己下、失败再用 yt-dlp；`ytdlp` 反过来 |
| `scanQuality` | 480 | 整片分镜用的清晰度（按短边：360 / 480 / 720）。不登录最高 480P；老视频只有 AVC 编码、估算超过 200 MB 时自动降一档。放大看另取直链，登录 1080P、不登录 480P |
| `cacheDir` / `mediaDir` / `mediaMaxMb` | — | 分镜缓存与下载视频的目录（默认在系统盘），下载视频的大小上限 |
| `ytdlpPath` / `ffmpegPath` | — | 不在 PATH 上时指定 |

## 谁叫的

见 [接入 QQ 机器人](接入QQ机器人.md#群里省着用谁叫她看视频)。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `askLookOwner` / `askLookFriend` / `askLookOther` / `askLookUnknown` | `full` | 看视频（含放大看）：主人 / 熟人 / 别人 / 说不清叫的，`full` 看 / `brief` 只看简介 / `off` 不看 |
| `askSurfOwner` / `askSurfFriend` / `askSurfOther` / `askSurfUnknown` | `full` | 逛，同上 |
| `askFriendQQ` | — | 熟人的 QQ 号，逗号或换行分开 |
| `askFriendPerDay` / `askOtherPerDay` | 0 / 0 | 熟人、别人每人每天最多让她新看几个（0 = 不限），超了「看」降成「只看简介」 |
| `askGroups` | — | 个别群换预设，写成「群号:预设」（`all` / `brief` / `friends` / `owner`），逗号或换行分开 |

## 逛

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `surfMode` | `explore` | `explore` 顺着逛（token 约是 `quick` 的 3~5 倍；模型不支持工具调用时自动用 `quick`）/ `quick` 固定流程 |
| `surfSteps` / `surfOpenMax` / `surfSeconds` | 12 / 6 / 120 | 顺着逛最多几步、最多打开几条视频、一圈最多几秒 |
| `surfPicks` / `surfCandidates` / `surfMaxSeconds` / `surfPerHour` | 3 / 24 / 3600 / 6 | 一圈挑几条、先找多少候选、候选最长多少秒、每小时最多逛几圈 |
| `surfTaste` | — | 逛的口味（给挑选那一步看） |
| `surfModel` | — | 挑选和总结用的模型 `provider/model`（空 = 跟调用它的会话一样） |

## 自己逛

见 [后台功能](后台功能.md#自己逛)。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `autoSurfOn` | false | 开关 |
| `autoSurfWindow` | `14:00-22:30` | 时间段（可跨午夜） |
| `autoSurfMin` / `autoSurfMax` / `autoSurfGapMinutes` | 1 / 2 / 60 | 每天至少 / 最多几次，两次至少隔几分钟 |
| `autoSurfComment` | true | 看情况自己评论 |
| `autoSurfLike` / `autoSurfFav` | true / true | 看情况点赞、收藏（每圈最多收藏一个）；还要权限表那一行能在后台做 |
| `autoSurfPost` | false | 特别喜欢的偶尔发条动态（每天最多一条）；还要「发动态」开着 |
| `autoSurfRecommend` | `notify` | 想推荐时怎么说：`notify` 门卫转达、`comment` 评论里 @ 主人、`dm` B站私信，逗号分隔可多选，空 = 不推荐 |
| `autoSurfVoice` | — | 她说话的样子。自己写评论、推荐语，以及守评论区、收件箱里回复别人时都照着这个口吻 |

## 收件箱

见 [后台功能](后台功能.md#收件箱)。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `inboxOn` | false | 后台查收件箱 |
| `inboxPollSeconds` / `inboxIntervalSeconds` | 60 / 600 | 多久看一次未读数；未读数没变时最晚多久也完整查一次 |
| `inboxQuiet` / `inboxQuietMode` | `00:30-07:30` / `hold` | 安静时段（可跨午夜，空 = 没有）；时段里 `hold` 照查但先攒着 / `skip` 不查 / `normal` 照常。守评论区也按它来 |
| `inboxDm` | true | 也查私信（只转达主人的，别人的只记下来） |
| `inboxReplyMode` | `wake` | 别人回复 / @ 她的评论：`wake` 叫醒她自己处理 / `notify` 只告诉主人 / `engine` 插件按权限表回 / `log` 只记下来 |
| `inboxChatChance` | 80 | 别人接她的话（闲聊）时回的概率（%） |
| `inboxReport` | `auto` | 处理完要不要告诉主人：`all` 都说 / `auto` 只说回了的 / `none` 不说。只在 `notify` / `engine` 时有用 |
| `inboxNotifyPerHour` | 6 | 每小时最多转达几次，守评论区共用。0 = 一律不转达（连主人自己的也不说） |

## 主人和权限表

见 [写操作与权限](写操作与权限.md#权限表)。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `ownerMid` | 0 | 主人的 B站 UID：@ 和私信只能对着它 |
| `friendMids` | — | 其他自己人的 UID（逗号或换行分开），只影响权限表按「自己人」算 |
| `permLikeOwn` / `permLikeOut` | `off` | 点赞、收藏 |
| `permCommentOwn` / `permCommentOut` | `off` | 顶层评论 |
| `permReplyOwn` / `permReplyHome` / `permReplyOut` | `off` | 回复 |
| `permFollowOwn` / `permFollowOut` | `off` | 关注 |
| `permDm` | `off` | 私信主人 |
| `permPost` | `off` | 发动态 |

权限表字段名里，`Own` 是自己人，`Home` 是主人评论区里的别人，`Out` 是外面的人。每格可选 `off` 关 / `asked` 主人开口才做 / `approve` 先问主人 / `auto` 直接做。0.6.0 的 `likeMode` … `followMode` 升级时自动换成这张表，行为不变。

## 额度和节奏

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `likePerDay` / `commentPerDay` / `replyPerDay` | 30 / 5 / 10 | 每天最多点赞、顶层评论、回复几次 |
| `dmPerDay` / `postPerDay` / `followPerDay` | 10 / 2 / 3 | 每天最多私信、动态、关注几次（关注和取关各自计，硬上限 10） |
| `writeGapSeconds` | 60 | 两次写操作至少隔多久 |
| `draftMinutes` | 60 | 草稿有效期 |
| `writePaused` | false | 全部停下 |

| --- | --- | --- |

## 收藏和关注

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `favFolder` | `AI 的收藏` | 她收藏的视频放进哪个收藏夹（没有就建一个公开的；留空 = 默认收藏夹），也是她能取消收藏的范围 |
| `favPerDay` | 10 | 收藏和取消收藏各自每天几个（档位和点赞共用「点赞、收藏」一行） |
| `followTag` | `AI 的关注` | 她关注的人放进 B站的哪个分组（没有就建），也是她能取关的范围；改名后旧分组里的人不会自动搬过来 |

## 门卫

见 [写操作与权限](写操作与权限.md#门卫) 和 [门卫协议](../门卫协议.md)。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `gateMode` | `auto` | 门卫来源：`auto`（桥接服务 > 门卫地址 > 内置）/ `dsh-qq`（插件自己当 dsh-qq 桥接的门卫，要填桥接目录）/ `builtin` |
| `qqBridgeDir` | — | dsh-qq 桥接目录 |
| `gateUrl` / `gateHeader` | — | 门卫地址（只能是本机 `http://127.0.0.1…`）和请求头（`名字: 值`） |
| `untrustedPresets` | — | 内置门卫：哪些 `agentPreset` 算桥接会话（正则，空 = `qq\|wechat\|weixin\|wx\|onebot\|napcat\|bot\|group`） |
| `untrustedCwd` | — | 内置门卫：哪些工作目录算桥接会话（一行一个） |
