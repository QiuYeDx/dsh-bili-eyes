# 设置页

DSH「设置」侧边栏里的「B站伙伴」。标题旁边显示当前版本号，npm 上有新版本时会写出来，点一下跳到「设置 → 关于」。

改动保存后立即生效，不用重启 DSH。

## 页签

共六个页签，每个页签下再分几块，一次只看一块：

| 页签 | 分块 | 内容 |
| --- | --- | --- |
| 概览 | — | B站登录（扫码 / 换账号 / 退出）；待办和今天：待同意的草稿、收件箱待处理、自己逛的下一次、今天的写操作（点一下直接跳过去），以及这一小时的用量；安装检查（都正常时收成一行，有问题时展开，ffmpeg 可一键下载） |
| 看视频 | 试看 · 记录 · 谁叫的 | 试看：贴链接或关键词，跑一遍和工具调用相同的流程；记录：她和设置页用过的看视频、搜索、逛一圈，可按「谁叫的」筛选；谁叫的：群里谁叫她看视频、逛，各看到哪一步 |
| 冲浪 | 刷列表 · 逛一圈 · 自己逛 · 路线 · 设置 | 预览几种列表（含她的收藏）；试跑逛一圈；自己逛的今天计划和最近结果；顺着逛的路线；怎么逛、自己逛的设置 |
| 收件箱 | 消息 · 设置 | 消息：待处理 / 全部，可标记处理完或忽略，「现在查一次」；设置：收件箱和门卫（含 dsh-qq 检查和一键适配） |
| 互动 | 概况 · 待同意 · 记录 · 守评论区 · 关注 · 收藏 · 表情 · 设置 | 账号等级、主人、权限表、今天各类用量；待同意的草稿；写操作记录；守评论区（盯哪些投稿、问答备忘、处理记录）；她的关注和收藏（可取关、取消收藏）；表情；权限表、自己人、额度、「怎么回」的规矩 |
| 设置 | 看视频 · 限额 · 存储 · 语音识别 · 关于 | 看视频的方式、限额；缓存占用和清理、路径检查；语音识别（可测试）；关于：版本、安装方式、检查更新、作者和仓库、交流群、这个版本更新了什么 |

## 交互约定

- 长列表（记录、消息、路线、自己逛的结果、关注、收藏）放在固定高度的框里滚动，底部写「显示 n / 共 m 条」。
- 记录和消息可以按类型、结果、时间范围（今天 / 7 天 / 30 天 / 全部）筛选，一次读 50 条，「加载更多」继续往下读。筛选和分页在接口那边做，不会一次读出全部历史。
- 页签和分块导航滚动时固定在顶部；一块里有多组设置时，导航右边有「跳到」。
- 配置文件里有超出范围的旧值（比如手改过）时，会在它所在的那组里标出来，不影响保存别的设置。

## 实现说明

- 页面数据走 DSH 自带 webServer 上的同源接口 `/api/bili-eyes`，登录 cookies 不会经过接口返回。宿主没有 webServer 时只注册工具，不挂设置页。
- 最近的记录存在 `~/.dsh/bili-eyes/history.jsonl`，只记标题、BV 号和用时，最多约 300 条。
- 本地调试设置页不用开 DSH，见 [开发](开发.md#本地预览设置页)。
